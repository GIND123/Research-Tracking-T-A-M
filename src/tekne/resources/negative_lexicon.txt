# Surfaces that must never be emitted as technology mentions.
#
# Three families, all of which a head-noun recaller will happily propose:
#   (a) patent drafting boilerplate -- high frequency, zero information
#   (b) bare generic nouns -- only technological once modified
#   (c) scholarly furniture -- section names, figure references, hedges
#
# Matching is case-insensitive over the lemmatised surface, with leading
# determiners stripped. See guard/negative.py.
